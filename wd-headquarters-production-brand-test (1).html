Drive 연결

기존 폴더 바로가기는 유지하고, File ID · 상태 · 마지막 검증은 데이터센터 원본지도를 기준으로 확인합니다.

🗄
실제 근거: WD 데이터센터 원본지도 본진은 Drive 계정명 · 폴더 경로 · Folder ID를 별도 원장으로 보관하지 않습니다.

GitHub 파일 안내

기존 파일 안내는 유지하고, repository · branch · 파일 · commit의 현재 근거는 데이터센터에서 확인합니다.

파일명연결 공간기존 안내 역할원본근거
로그인 · 토큰 · 비밀번호 · API Key는 표시하지 않습니다.
접속정보는 WD 업무센터의 계정관리에서 확인하고, 본진 연결지도에는 복제하지 않습니다.
