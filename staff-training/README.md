- 용도: **알바·인턴 업무지시 및 실무보고용**
- 소유 저장소: `Sara-cho/wd-admin`
- 작업 브랜치: `test/staff-training-app-261105`
- 상태: **비운영 준비 / 앱 HTML 업로드 및 실기능 검수 미완료**
- 기존 본진 운영본(`main/index.html`), 배포 설정, 인증, 고객정보는 변경 금지.

## 확정된 업무 흐름
1. 업무지시자가 월별 업무와 개별 할 일·가이드·참고 링크를 입력
2. 직원이 업무지시 읽음 확인(첫 읽음 시각 기록) 후 **각 할 일마다 별도 업무보고** 작성
3. 수행 과정: 조사 계획 → 출처·캡처 → 비교 및 선정 이유 → 실행 결과 → 필요 시 파일·사진·영상·링크 다중 첨부
4. 업무지시자(지점장/대표)가 각 업무를 검토하여 번호가 붙은 피드백, 참고 첨부 및 승인·수정 요청
5. 직원이 수정·재제출; 제출/수정 이력 보존
6. 직원 사이드바: 월간 업무 목록 / 업무 대시보드 / 제출 업무보고 / 자료·아이디어 저장
